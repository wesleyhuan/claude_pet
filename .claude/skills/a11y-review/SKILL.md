---
name: a11y-review
description: TDD accessibility + UX review of a React component
---
For the component I name:
1. Write failing tests first (focus trap via useModalFocus, Escape-to-close, aria-labels, WCAG AA contrast).
2. Implement the minimal fix.
3. Run the full test suite and report a before/after diff summary.
Use inline SVG icons, never emoji.
